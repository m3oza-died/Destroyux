## Setup

1. Create bot at [discord.com/developers/applications](https://discord.com/developers/applications)
2. Copy `.env.example` → `.env`
3. Add `BOT_TOKEN` and `OWNER_ID`
4. `pip install -r requirements.txt`
5. `python main.py`

## Deploy to Railway

1. Push to GitHub
2. Connect to Railway
3. Add env: `BOT_TOKEN`, `OWNER_ID`
4. Deploy
