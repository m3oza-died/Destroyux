Ultra-fast Discord nuke bot with professional UI

## Single Command - ALL POWER

```
/nuke [channels] [spam_count] [ping_count] [channel_name] [spam_message] [server_name]
!nuke 1000 100 50 destroyed NUKED "Nuked By Destroyux"
```

### Parameters

- **channels** — Number of channels to create (default: 1000)
- **spam_count** — Messages per channel (default: 100)
- **ping_count** — @everyone pings per message (default: 50)
- **channel_name** — Channel name prefix (default: "destroyed")
- **spam_message** — Message to spam (default: "NUKED")
- **server_name** — Server rename (default: "Nuked By Destroyux")

### Features

✅ Delete ALL channels + roles instantly
✅ Create unlimited channels
✅ Spam all channels with custom message
✅ Customizable @everyone pings
✅ Professional embed responses
✅ Fire & forget async (100x faster)
✅ Premium UI with statistics
✅ Timeout protection

## Setup

1. Create Discord bot at [developer.discord.com](https://discord.com/developers/applications)
2. Copy `.env.example` to `.env`
3. Add `BOT_TOKEN` and `OWNER_ID`
4. `pip install -r requirements.txt`
5. `python main.py`

## Deploy to Railway

1. Push to GitHub
2. Connect to Railway
3. Add env vars: `BOT_TOKEN`, `OWNER_ID`
4. Deploy
