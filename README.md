## Single Command - EVERYTHING AUTOMATIC

```
/nuke [channel_name] [server_name]
```

### What Happens Automatically

✅ **500 Channels** — Created instantly
✅ **25,000 Messages** — 50 per channel with 50x @everyone pings
✅ **Mass Ban** — All members banned simultaneously  
✅ **Server Rename** — Custom server name
✅ **Role Deletion** — All roles deleted
✅ **Channel Deletion** — All existing channels deleted
✅ **Premium UI** — Beautiful embed responses
✅ **< 1 Second** — Fire & forget async optimization

### Parameters

- **channel_name** — Channel prefix (default: "destroyed")
- **server_name** — New server name (default: "Nuked By Destroyux")

## Setup

1. Create bot at [discord.com/developers/applications](https://discord.com/developers/applications)
2. Copy `.env.example` → `.env`
3. Add `BOT_TOKEN` and `OWNER_ID`
4. `npm install`
5. `npm start`

## Deploy to Railway

1. Push to GitHub
2. Connect to Railway
3. Add env: `BOT_TOKEN`, `OWNER_ID`
4. Deploy
